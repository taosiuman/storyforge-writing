# A-world-engine — 世界引擎（封存 / 出口）子契约（v0.2.0 新增）

> 来源：`H:\storyforge-main\docs\products\WORLD-ENGINE.md`（主基线）。
> 本契约覆盖技能的**世界侧**职责：封存、能力画像、数据出口、分享包；**不含**世界草稿的领域编辑细节。

## 1. 草稿与不可变版本

| 对象 | 性质 | 关键规则 |
| --- | --- | --- |
| 世界草稿 | 可编辑、不断变化 | **不可直接作为可重复构建来源** |
| `worldCode` | 稳定编号 | **不因草稿修改而改变**（可分享世界的身份） |
| `WorldRelease` | 不可变封存产物 | 含 **world code、version、content hash、schema version、能力画像、目录与来源 manifest** |

- 上层产品**锁定 release ID/hash**；世界草稿后续修改**不影响**已有产品。
- 世界新版本**从新草稿显式封存**，**不覆盖**旧版本。
- 同一世界 release 可被**多个相互隔离的产品实例**引用；仅世界来源改变**不**代表产品必须自动升级。

## 2. 世界出口契约（§5.2「不统一什么」）

**世界出口不定义一份让所有上层产品照单全收的通用 payload**，也不预设某类产品的角色卡、规则、游戏时长、结局或运行字段 ——
不同产品需要的数据广度、细节层级和证据类型可以完全不同。

每个上层产品在**自己的 `S2 产品定向`契约**中提供 `WorldRequirementAdapter`（名称按实现可调），把当前用户目标与产品配置转换成四类：

1. 稳定必读
2. 建议/选读
3. 条件读取
4. **禁止读取**

网关只负责**在指定不可变 release 内**可靠地解释和满足这些需求；产品侧可继续排序、组合或请求补充读取，
但**不得绕过协议查询世界底表**。

- 适配器由**类型化代码/配置 + 产品 Skill 协作**：代码/schema 固定版本、权限、必读与禁止边界；Skill/Prompt 处理开放式目标与语义查询。
- **不能只靠提示词声明"必须读取"**，也**不得把世界物理表名复制进每个产品**。

## 3. 数据出口（作者侧）

- 通过**中立客户端**分页检索、读取资源及**原文证据**。
- 分别显示：**已确认 / 候选 / 冲突 / 未收录 / 本次封存选择范围**。
- 修改返回**世界草稿**（不在出口侧直接改 release）；产品定向设置留在各产品 `S2`。

## 4. 分享与导入

- 选择**历史发布版本** → 设置作者、许可、用途与内容警告 → 下载 **JSON 包**。
- 导入：**先预检**，再由作者确认**创建新编号副本**（不覆盖原世界）。
- **在线社区发布与社区数据尚未接入**（页面须明确此边界）。

## 5. 版本页与已知缺口

- 可冻结修订发布、保留历史不可变版本；差异**目前只显示最新两次修订的表级增改删计数**，
  **不提供**未实现的逐字段恢复按钮。
- 世界名称与简介由独立 World 元数据入口修改并校验新鲜度；故事/大纲/细纲/正文是**可选**语义内容，
  **不成为所有世界的完成门槛**。

## 6. 本技能的执行边界

- 本 skill 可**生成**可封存的世界语料（世界草稿语义）与**出口包的结构说明**，
  **不代替** StoryForge 的封存/出口运行时（不操作 IndexedDB、不代作者点击）。
- 涉及上层产品读取时，产出必须给出 `WorldRequirementAdapter` 的四类清单**建议**（稳定必读/建议·选读/条件读取/禁止读取），
  并明确该建议属**候选**（作者/产品侧确认后生效）。
